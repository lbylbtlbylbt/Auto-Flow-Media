# Contributing

Open an issue for a proposal or a pull request against main. Include the intended behavior, steps to reproduce the issue and the platforms tested. Run `node --test test.mjs` before submitting. For playback changes, also follow the manual checks in the README. Format changes should include an updated specification and a compatibility example.

By submitting a contribution you agree to license it under the repository's MIT License. Submit work you have permission to share, credit its authors and identify any dependencies and their licenses. Use synthetic media or fixtures that can be redistributed. Follow the [code of conduct](CODE_OF_CONDUCT.md) and use the [security reporting process](SECURITY.md) for sensitive reports.
