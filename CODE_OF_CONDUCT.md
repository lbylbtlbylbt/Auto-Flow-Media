# Code of conduct

Treat contributors and users with respect. Give specific feedback on the work. Welcome differences in experience, background and opinion. Harassment, threats, discriminatory abuse, publishing private information and repeated unwanted contact are unacceptable.

This policy applies in project issues, pull requests and other project-managed spaces. Use GitHub's private Report abuse option for harassment or privacy violations. When raising a moderation concern with the repository owner, share only information you are comfortable disclosing. Maintainers may edit or remove content, restrict participation or ask GitHub to intervene. They should apply the same standards to every participant and protect reporters' privacy.
